Claude Code로 삽질한 과정(문제 → 시도 → 실패 → 해결)은 이미 전부 기록되고 있습니다. session-retro는 그 기록이 사라지기 전에 건져서, 사람이 읽을 수 있는 velog 글과 발표 덱으로 바꿔줍니다.

/retro

세션을 증류해 회고 스펙(retro/spec.md)을 만들거나 갱신. 세션 중간에 다시 부르면 체크포인트.

/retro-blog

스펙 → velog 글 초안 → 이미지 업로드 → 임시저장까지 자동. 발행 버튼은 내가.

/retro-ppt

스펙 → 단일 파일 HTML 발표 덱. ←/→로 넘기고 Ctrl+P로 PDF.

처음 한 번만 하면 되는 것

  1. 설치 — 저장소에서 bash install.sh (스킬 3개 연결 + 백업 훅 등록, 기존 설정은 백업 후 병합)
  2. 프로젝트 활성화 — 회고를 남기고 싶은 프로젝트에서 /retro 한 번. retro/ 폴더가 생기는 순간부터 그 프로젝트의 세션이 자동 백업됩니다.
  3. velog 토큰 (블로그 쓸 때 최초 1회) — velog.io 로그인 → F12 → Application → Cookies에서 access_token·refresh_token 복사 → python3 skills/retro-blog/scripts/velog_publish.py setup
  4. 권장 — ~/.claude/settings.json에 "cleanupPeriodDays": 90 (원본 보존 기간 30→90일)

안전 원칙

초안까지만velog엔 항상 임시저장으로만 올립니다. 공개 발행 버튼은 사람이 누릅니다.
글은 절대 안 사라짐업로드가 실패해도 MD 파일이 로컬에 남아 에디터에 붙여넣으면 끝.
비공식 APIvelog는 공식 API가 없어 내부 API를 씁니다. 깨질 수 있지만, 깨져도 위 폴백이 있습니다.
훅은 무해retro/ 있는 프로젝트에서만, 복사만, 실패해도 세션에 영향 0.
토큰은 로컬에만~/.config/velog-retro/(0600). 채팅·로그·git에 노출하지 않습니다.

막혔을 때

업로드가 실패했어요

글은 이미 retro/out/blog/에 있습니다. velog 에디터에 통째로 붙여넣고 이미지를 드래그하세요. *.published.md가 있다면 이미지가 이미 CDN URL로 치환된 것이니 그 파일을 쓰면 이미지 작업도 필요 없습니다.

토큰이 만료됐대요

쿠키를 다시 복사해서 python3 skills/retro-blog/scripts/velog_publish.py setup을 다시 실행하면 됩니다. (access_token 수명 ~1시간, refresh_token ~30일 — 평소엔 자동 회전됩니다.)

훅이 백업을 안 해요

① 그 프로젝트에 retro/ 폴더가 있나요? (/retro 한 번 실행) ② 설치 후 새로 시작한 세션인가요? ③ retro/archive/.hook.log에 기록이 남습니다.

이미 한참 진행된 프로젝트인데 지금 도입해도 되나요

네 — 그 시나리오가 소급 모드입니다. 첫 /retro가 세션 기록(30일 보관)과 git 커밋을 교차한 인벤토리를 만들어 기능/문제 단위 에피소드를 나눠 제안하고, 승인한 것부터 스펙(블로그 1편감)과 온보딩용 개요(overview.md)를 만듭니다. 한 에피소드가 너무 길면 1부/2부 분할을 제안합니다. 세션이 이미 지워진 구간은 git 커밋 뼈대 + 짧은 인터뷰("이때 뭐가 힘들었어요?")로 보완합니다.

지난주에 한 세션도 회고로 만들 수 있나요

네. 원본이 ~/.claude/projects/에 30일간 남아 있어 /retro가 소급 수집합니다. 그래서 보존 기간을 90일로 늘려두길 권장합니다.

스킬을 부르는 걸 자꾸 잊어버려요

세션 시작 넛지 훅이 대신 기억합니다 — 회고 재료가 쌓인 프로젝트에서는 Claude가 마무리 시점에 먼저 체크포인트를 제안하고, 회고가 활성화되지 않은 프로젝트에서 회고·블로그 얘기가 나오면 소급 모드를 안내합니다.

PPT를 .pptx 파일로 받고 싶어요

v1은 HTML 덱 + 인쇄 PDF까지입니다. HTML→pptx 자동 변환은 슬라이드가 이미지로 박제되는 한계가 있어, 편집 가능한 .pptx는 v2(PptxGenJS 경로)로 계획되어 있습니다.
